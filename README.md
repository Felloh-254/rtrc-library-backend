# RTRC Library Management System Backend

Backend API built using FastAPI for the RTRC Library Management System.

## Technologies

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication

## Running locally

Create virtual environment:

```bash
python -m venv .venv

Install dependencies:

pip install -r requirements.txt

Run server:

uvicorn app.main:app --reload
```
